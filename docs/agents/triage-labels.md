# Triage labels

Use these exact GitHub label strings when a skill refers to a canonical triage role.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The issue needs more information from its reporter. |
| `ready-for-agent` | `ready-for-agent` | The work is specified and ready for agent implementation. |
| `ready-for-human` | `ready-for-human` | The work requires human implementation. |
| `wontfix` | `wontfix` | The proposed work will not be implemented. |

Inspect existing repository labels before applying this mapping. Create a missing label only when the invoked workflow authorizes that change.

This mapping does not confirm that the five labels already exist. A readiness label describes work status; it does not authorize publication or other external actions.

Edit the GitHub label column if the repository adopts another vocabulary.
